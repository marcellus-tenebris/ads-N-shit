# ads-n-stuff
A personal collection of uBlock Origin filters for blocking unwanted ads, annoyances, and other things I don't want on the web.

# Disclaimer
This is a personal filter list, maintained primarily for my own use. It may cause website breakages, interfere with website functionality, or produce unexpected results.
It is not designed or tested to work perfectly on every website.
You may need to create exceptions if something breaks.
Use at your own risk. 
No warranty or support is provided.

# Usage
You are welcome to use, modify, and redistribute this list.
It is public primarily to allow automatic updates across my own devices, but anyone is free to use it.
